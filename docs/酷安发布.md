# 自动旁路供电 v10.0 —— 让插着电的设备不再"喂"电池

**一句话**：插着充电器打游戏不发烫，电池也不再一直被顶在 100%。

---

## 你有没有这种场景

平板或手机长期插着电用，电池永远 100%，机身温热，电池健康肉眼可见地掉。

其实厂商自己就有解法 —— 小米的「夜间充电」（智慧充电保护）：夜里充到某个电量就暂停，
早上再充满。它的本质不是断电，而是**暂停给电池充电、设备改由适配器供电**，也就是旁路。

这个模块做的事很简单：**把那个开关交给你**，充到多少停、掉到多少恢复，你说了算。

---

## 为什么要重做这一版

原版（酷安 @柳下惠77）是很好的思路，但只测到 MIUI / HyperOS 1。

新系统把控制节点挪了位置 —— 从 `battery/night_charging` 搬到了 `smart_charge` 平台下，
而且不同机型层级还不一样（平板上是 `platform/smart_charge`，手机上是 `platform/soc/soc:smart_charge`）。

结果就是：**很多人刷上去发现完全没反应**，日志里只有一行"未找到控制节点"。

这一版把节点改成自动探测，换机型不用改代码。

---

## 实测数据

| 测试 | 结果 |
|---|---|
| 开启旁路后库仑计变化 | `charge_counter` Δ = **0**，电池既不充也不放 |
| 电池电流 | -584000 µA（充电）→ +35000 µA（停止） |
| 电量 93% 时把阈值改成 95% | **1 秒内**恢复充电 |
| 连续观察 60 秒 | 无反复开关，稳定保持 |

`Δ=0` 是最关键的证据：如果只是简单停止充电，设备运行会持续吃电池电量（Δ 为负）。
实测 Δ=0，说明供电确实切到了适配器，电池处于静置状态。

## 特性

- **图形控制面板**（KsuWebUI）—— 实时电量 / 电流 / 温度，一键开关，拖滑块改阈值，看运行日志
- **任意阈值** —— 1~100 随便设，不受厂商界面的 80% 下限限制
- **改完 1 秒生效** —— 不用重启，不用等巡检周期
- **自动识别机型** —— 不同厂商 sysfs 层级差异自动适配
- **不会重复启动** —— 原子锁保证单实例
- **写入有校验** —— 配置写失败会明确报错，不会装成功

## 适用条件

- 小米系设备，且系统里有 `smart_charge` / `smart_night` 节点
- 已 root：KernelSU / SukiSU Ultra / Magisk / APatch 均可

自查命令（有输出就能用）：

```bash
su -c 'find /sys/devices -maxdepth 7 -name "smart_night"'
```

**已验证机型**：

- 小米平板 7 Ultra（`25032RP42C`）— HyperOS 4.0.0.13 / Android 17 / KernelSU 3.3.1
- 小米 17（`25113PN0EC`）— HyperOS 4.0.5 / Android 17 / SukiSU Ultra 4.2.1

---

## 安装

1. 下载 zip
2. KernelSU / Magisk 管理器 → 模块 → 从本地安装
3. 重启

默认 **80% 停止充电 / 75% 恢复充电**。

## 使用

管理器 → 模块 → 自动旁路供电 → **WebUI**

不想用界面也行，直接改 `/data/adb/modules/bypass_charger/config.sh`，改完立刻生效。

---

## 注意

- 系统弹「智慧充电保护：电量达 xx% 已暂停充电」是**正常现象**，说明模块生效了。
  **别点那条通知里的「立即充满」**，点了就是取消旁路。
- 卸载后节点自动恢复默认值，不留残留。
- 模块改的是厂商已有的开关，不动电流电压温度保护，安全性等同于你自己在设置里开夜间充电。
- 改系统充电行为有风险，请自行评估。
